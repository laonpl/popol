## 0. 요약 (TL;DR)

- **트랙 A (영상):** 직군별 숏폼 영상 4편으로 "어떤 직군이 FitPoly 메시지에 반응하는가"를 검증한다. 판정 지표는 훅 시청률·CTR·가입 전환율·직군별 CAC.
- **트랙 B (결제의사):** 영상으로 유입된 사용자의 **크레딧 소모 퍼널**(활성화 → 소진 → 충전)로 결제의사를 검증한다. 판정 지표는 활성화율·소진 도달률·소진→결제 전환율.
- 모든 목표치는 ① 자사 실측 베이스라인, ② 업계 공개 벤치마크, ③ 마진 구조(공헌이익)에서 역산했다. 근거 없는 수치는 없다.
- **선결 과제 2개**가 있다: 결제 pending 9건/완료 0건의 원인 규명(§6-1), 직군별 UTM·이벤트 로깅(§7). 이거 없이 실험을 시작하면 데이터를 버리게 된다.

## 1. 검증하려는 핵심 가설

| # | 가설 | 검증 트랙 | 성공 판정 |
|---|---|---|---|
| H1 | 직군별로 맞춤화된 메시지는 범용 메시지보다 반응이 높고, **특히 반응이 집중되는 직군이 존재한다** | A | 최고 직군의 가입 전환율이 4개 직군 평균 대비 **+50% 이상** |
| H2 | 영상을 보고 유입된 사용자는 오가닉/지인 유입보다 **활성화율이 높다** | A→B | 영상 유입 활성화율 ≥ 25% (베이스라인 13.7%의 약 2배) |
| H3 | 무료 크레딧(2,000C)을 소진할 만큼 가치를 느낀 사용자 중 일부는 **실제로 결제한다** | B | 소진 도달자의 **10% 이상 결제** 또는 전체 가입자의 **2% 이상 결제** |
| H4 | 크레딧 소모 패턴(어떤 기능에 쓰는가)이 직군별로 다르며, 이것이 직군별 고도화 우선순위를 알려준다 | B | 직군별 기능 사용 분포에 유의미한 차이 존재 |

## 2. 실험 설계 개요

| 항목 | 설정 | 근거/비고 |
|---|---|---|
| 기간 | **4주** (2주 운영 + 중간 점검 → 2주 운영) | 숏폼 광고 학습 기간(3~7일) + 가입 후 소진까지의 행동 관찰 기간(7~14일)을 모두 포함해야 함 |
| 채널 | Instagram Reels / YouTube Shorts (동일 소재 교차 게시) | 타겟(취준생 20대)의 주 이용 매체. 오가닉 먼저 → 반응 좋은 소재만 소액 부스트 |
| 소재 | 직군별 1편 × 4직군 (개발자 / 기획자·PM / 디자이너 / 마케터) | 각 영상은 해당 직군의 실제 산출물 화면(직군 특화 섹션·포트폴리오)을 보여줌 |

| 표본 하한 | 직군당 노출 **최소 15,000회**, 가입 **최소 20명** | CPM ₩7,000~10,000 가정 시 ₩150,000으로 15,000~21,000 노출 확보 가능. 이보다 표본이 작으면 직군 간 비교 판정을 유보한다(§5) |
| 유입 식별 | 직군별 UTM 링크 + 가입 시 직군 선택값 매칭 | §7 참고 |

## 3. 트랙 A — 직군별 영상 반응 검증

측정 단위: **직군별 영상 각각** (합산이 아니라 직군 간 비교가 목적)

| 지표 | 정의 · 측정 | 목표치 | 목표치 근거 | 달성 시 플랜 | 미달 시 플랜 |
|---|---|---|---|---|---|
| **훅 시청률** | 3초 이상 시청 ÷ 노출 | **≥ 25%** | Meta 숏폼 광고 훅 레이트 업계 평균 20~30%¹. 무명 브랜드이므로 중앙값으로 설정 | 소재 유지, 해당 직군 예산 증액 | 첫 3초를 직군 페인포인트 자막으로 교체 (예: "포트폴리오에 쓸 게 없는 3년차 마케터") 후 1주 재측정 |
| **완주율(15초)** | 15초 이상 시청 ÷ 3초 시청 | **≥ 40%** | 훅 통과자 기준 15초 유지율은 통상 30~50%¹. 제품 데모형 영상은 중반 이탈이 큼 → 중앙값 설정 | 동일 구조로 나머지 직군 영상 개선 | 중반부(제품 화면)를 결과물 먼저 → 과정 순서로 재편집 |
| **CTR (링크 클릭)** | 링크 클릭 ÷ 노출 | **≥ 1.0%** | Meta 전 산업 평균 CTR 약 0.9~1.0%² . 직군 타겟팅으로 평균 이상을 노리되 하한은 평균으로 | CPC 확인 후 예산 증액 | CTA 문구를 직군 결과물 중심으로 교체 ("내 경험이 개발자 포트폴리오가 되는 과정 보기") |
| **CPC** | 지출 ÷ 링크 클릭 | **≤ ₩1,000** | 국내 Meta 트래픽 캠페인 CPC 통상 ₩500~1,500² 의 중앙값 | — | CTR 개선이 우선 (CPC는 CTR의 종속변수). 훅·CTA 수정 후에도 초과 시 해당 직군 중단 |
| **랜딩 → 가입 전환율** | 가입 완료 ÷ 랜딩 방문 (직군 UTM별) | **≥ 3%** | 전 산업 랜딩 전환 중앙값 4.3%³ 이나, 소셜 유입은 검색 대비 의도가 낮아 -30% 보정 | 랜딩 유지 | 3% 미만이면 영상-랜딩 메시지 불일치 의심 → 직군별 랜딩 진입 구간(직군 결과물 먼저 노출) 실험 |
| **직군별 CAC (가입)** | 직군 지출 ÷ 직군 가입자 | **≤ ₩5,000** | 역산: CPC ₩1,000 × 전환 3% = 가입당 ₩3.3만은 부스트만으로는 불가 → 오가닉 도달 포함 혼합 CAC 기준. ₩5,000은 standard 결제 1건 공헌이익(₩7,713⁴)보다 낮아 "결제전환율 65%면 회수"되는 학습 비용 상한 | 최저 CAC 직군에 잔여 예산 집중 | 전 직군 ₩5,000 초과 시 유료 확산 보류, 오가닉(커뮤니티·에브리타임 등) 중심으로 전환 |
| **직군 간 차이 (H1)** | 직군별 가입 전환율 비교 | 최고 직군이 평균 대비 **+50%** | +50%는 표본 20~30명 수준에서 우연 변동(±30%p 내외)을 넘는 실질 차이의 하한 | **해당 직군을 주력으로 선언** — 랜딩·온보딩·다음 분기 기능 로드맵을 해당 직군 우선으로 재배치 | 차이가 +50% 미만이면 "직군 특화" 가설 기각 → 범용 메시지 1편과 성능 비교 후 직군화 투자 축소 |
| **정성 피드백** | 댓글·DM·가입 후 설문 "어떤 영상 보고 오셨나요" | 직군당 **유효 피드백 10건** | 정성 데이터는 표본이 아니라 포화(같은 얘기 반복)가 기준 — 통상 8~12건이면 패턴 포착 | 반복 언급되는 기대사항 → 백로그 상단 | 피드백 0~3건이면 영상 말미에 질문형 CTA 추가 ("당신 직군도 필요하면 댓글") |

> ¹ ² ³ ⁴ 출처는 §8.

## 4. 트랙 B — 크레딧 소모 기반 결제의사 검증

측정 단위: **영상 유입 코호트** (UTM 기준. 오가닉 코호트와 분리 집계해 H2 비교)

퍼널: `가입 → 첫 AI 실행 → 전체 분석 1건 완료 → 크레딧 50% 소모 → 90% 소진 → 충전 페이지 → 결제`

| 지표 | 정의 · 측정 | 목표치 | 목표치 근거 | 달성 시 플랜 | 미달 시 플랜 |
|---|---|---|---|---|---|
| **활성화율** | 가입 후 72시간 내 첫 AI 기능 실행 ÷ 가입 | **≥ 25%** (스트레치 40%) | 자사 베이스라인 13.7%는 온보딩·유입 의도 없이 달성한 수치. 영상 유입은 의도가 명확하므로 2배 설정. SaaS 활성화 중앙값 30%대⁵ 를 스트레치로 | 온보딩 유지, 트래픽 확대 | 25% 미만이면 가입 직후 이탈 구간 분석 → 첫 화면에서 "3분 만에 첫 경험 카드" 강제 온보딩 실험 |
| **아하 모먼트 도달률** | 가입 7일 내 경험 전체 분석 1건 완료 ÷ 활성 사용자 | **≥ 50%** | 전체 분석 1건 = 625~790C⁴로 무료 2,000C 내 충분. 첫 기능을 실행한 사람의 절반이 핵심 가치까지 못 가면 중간 UX 문제 | 분석 결과 화면에 포트폴리오 생성 유도 배치 | 어느 단계(자료 업로드? 분석 대기?)에서 새는지 단계별 이탈률 계측 → 최다 이탈 단계 1개만 수리 후 재측정 |
| **크레딧 50% 소모율** | 가입 14일 내 1,000C 이상 사용 ÷ 활성 사용자 | **≥ 40%** | 1,000C = 전체 분석 1건 + 공고 분석 1건⁴. "핵심 가치를 맛본 뒤 두 번째 행동"의 지표. 아하 도달자(50%)의 대부분 + α로 설정 | — | 아하 도달 후 멈추면 "분석 1회로 충분한 제품"이라는 신호 → 반복 사용 동기(공고별 맞춤 첨삭) 노출 강화 |
| **무료 크레딧 90% 소진 도달률** | 가입 30일 내 1,800C 이상 사용 ÷ 활성 사용자 | **≥ 15%** | 조정 후 평균 사용자 환산 사용량은 ~1,666C로 2,000C에 못 미침(실측⁴) → 소진은 상위 사용자에게만 발생. 활성자 중 상위 15%가 평균의 2배를 쓴다는 파레토 가정 | 소진 시점 = 결제의사 검증 모수 확보 → §아래 | 15% 미만이면 결제 검증 자체가 불가능 (§6-2) → 무료 크레딧 축소(2,000→1,000C) A/B 또는 프리미엄 기능 페이월 실험으로 소진 시점을 앞당김 |
| **소진 → 충전 페이지 방문율** | 소진(잔액<200C) 후 7일 내 충전 페이지 방문 ÷ 소진자 | **≥ 50%** | 소진자는 이미 가치를 소비한 최고 인텐트 집단. 절반도 가격을 안 본다면 소진 안내 UX 문제 | — | 크레딧 부족 모달에서 충전 페이지 직행 동선 점검 (현재 pending 9건이 이 구간 문제일 가능성) |
| **소진 → 결제 전환율 (H3 핵심)** | 소진 후 14일 내 결제 완료 ÷ 소진자 | **≥ 10%** | freemium 무료→유료 전환 업계 통상 2~5%⁶는 *전체 가입자* 기준. 소진자는 자기선택된 헤비유저이므로 전체 기준의 2~5배인 10%로 설정 | **결제의사 검증 성공** → 가격 유지, 유료 채널 확대. 패키지별 선택 분포로 가격 최적화 | 0~5%면 소진자 5명 이상 인터뷰(무엇이 있으면 결제했겠는가). 가격이 문제면 첫 충전 50% 할인 쿠폰 실험, 가치가 문제면 결제 전 기능 고도화로 회귀 |
| **전체 가입 → 결제 전환율** | 결제 완료 ÷ 가입 (30일) | **≥ 2%** | freemium 하한 벤치마크 2%⁶. 신규 서비스 첫 검증이므로 하한 채택 | standard(₩12,000) 기준 가입자당 기대 공헌이익 ₩154 → 허용 CAC 재계산 후 유료 확대 | 소진 도달률이 정상인데 결제만 0이면 가격 구조 재검토(§6-1 결제 UX 먼저 배제할 것) |
| **PMF 설문 (Sean Ellis)** | "FitPoly를 더 못 쓰게 되면?" — 활성 사용자 대상, "매우 실망" 응답 비율 | **≥ 40%** | Sean Ellis PMF 기준선 40%⁷ (Superhuman 등 검증 사례) | PMF 신호 → 성장 투자 정당화 | 40% 미만이면 "매우 실망" 응답자의 공통 직군·사용 패턴을 찾아 그 세그먼트에 집중 (전체 평균보다 세그먼트 PMF가 중요) |
| **직군별 기능 사용 분포 (H4)** | 직군별 기능당 크레딧 소모 비중 | 직군 간 상위 기능이 **서로 다르면 성립** | 탐색적 지표 — 사전 목표치 대신 분포 차이 자체가 산출물 | 직군별 최다 사용 기능을 해당 직군 영상 소재·온보딩 첫 기능으로 배치 | 분포가 동일하면 직군 특화 섹션이 안 쓰인다는 뜻 → 특화 섹션 노출 위치 점검 |

## 6. 알려진 구조적 리스크 (실험 전 반드시 처리)

### 6-1. 결제 pending 9건 / 완료 0건 — 선결 과제

가격 검증 이전에 **결제가 기술적으로 되는지**부터 확인해야 한다. pending 9건의 로그를 확인해 (a) PG 콜백 누락, (b) 사용자 중도 이탈, (c) 결제창 오류를 분리할 것. **(a)나 (c)라면 트랙 B의 결제 지표는 전부 무효가 된다.**

### 6-2. 무료 2,000C가 "너무 충분한" 문제

크레딧 차감률 조정(×2,500) 이후 평균 사용자의 환산 사용량은 ~1,666C로 **무료 범위 안**이다. 즉 평균적인 사용자는 결제 압력을 영원히 못 느낀다. 소진 도달률 15% 미달 시 이 실험은 결제의사를 검증할 모수 자체를 못 만들므로, 미달 플랜(무료 크레딧 축소 A/B 또는 페이월)을 미리 준비해 둔다. 단, 축소 실험은 활성화율을 해칠 수 있으므로 **트랙 B 2주차 데이터 확인 후** 투입한다.

### 6-3. 코호트 오염

지인·재방문 사용자가 영상 UTM 링크로 들어오면 전환율이 과대측정된다. 가입 설문 1문항("어떻게 알게 되셨나요")으로 교차 검증한다.
