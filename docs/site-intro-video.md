# FitPoly 서비스 소개 영상

`/video`의 60초, 16:9 모션그래픽입니다. 삼성페이 종합편(Heimate)의 밝은 배경,
파란 입체 소품, 시간대별 기능 소개와 로고 범퍼를 참고해 FitPoly의 경험 정리 흐름으로 구성했습니다.
레퍼런스 영상이나 음원은 결과물에 포함하지 않았으며, 배경음악은 렌더 스크립트에서 합성합니다.

## 결과물

- 페이지: `/video` — 재생, 일시정지, 탐색, 음악 켜기, 전체 화면, 다운로드
- 영상: `frontend/public/video/fitpoly-intro.mp4` — 1920×1080, 30fps, H.264/AAC
- 배경음악: `frontend/public/video/fitpoly-intro-music.mp3`
- 장면과 문구: `frontend/src/pages/SiteIntroVideo.jsx`
- 입체 소품과 모션: `frontend/src/pages/SiteIntroVideo.css`

기존 `backend/fitpoly-intro.mp4`는 보존합니다. 새 영상은 위 public 경로에 생성됩니다.
브라우저는 음소거 상태로 자동 재생하며, 모션 최소화 설정 시 정지된 인트로로 시작합니다.
Space로 재생/일시정지, 방향키로 5초 이동할 수 있습니다. 영상은 마지막 화면에서 정지합니다.

## 다시 렌더링

프론트엔드를 `frontend`에서 `npm run dev`로 실행한 다음, `backend`에서 실행합니다.

```powershell
npm run capture:intro
```

기존 Puppeteer와 ffmpeg-static 개발 의존성을 사용합니다. 중간 파일은 운영체제의 임시 폴더에
생성하고, 렌더가 성공한 경우에만 완성된 MP4를 public 경로에 복사합니다.
재생 시간과 CSS 애니메이션은 동일한 시계를 사용합니다. 새 장면의 이미지와 폰트를 먼저
로딩하고, 각 프레임에서 Chrome의 화면 합성이 완료된 뒤 캡처합니다.

음악만 다시 만들려면 `node scripts/render-site-intro.mjs --audio-only`를 실행합니다.
문구나 장면을 수정했다면 MP4를 다시 렌더링한 후 `frontend`에서 `npm run build`를 실행해야
웹 미리보기와 다운로드 영상이 동일한 상태로 배포됩니다.

## 확인

`backend`에서 `node scripts/review-intro.mjs`를 실행합니다. 각 장면의 이미지 누락과 글자 잘림,
장면 경계, 역방향 탐색의 프레임 일치, 일시정지, 끝에서 다시 재생, 음악 제어,
모바일·데스크톱 화면 비율, 모션 최소화 설정 및 런타임 오류를 확인합니다.
검토용 스크린샷은 출력에 표시되는 임시 폴더에 저장됩니다.
