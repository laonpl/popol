# FitPoly 로컬 탐색기

배포 사이트에서 처음 연결할 때 압축을 풀고 **FitPoly-자동연결-설정.cmd**를 한 번 실행하세요. Node.js가 포함되어 별도 런타임 설치가 필요 없습니다.
현재 Windows 계정의 `%LOCALAPPDATA%\FitPoly\local-experience`에 연결 기능을 설치하고 Windows 로그인 시 자동 시작을 등록합니다. 관리자 권한은 필요 없습니다.
사이트의 **설정한 PC 연결 열기**를 누르면 `fitpoly-local://connect` 앱 연결을 열어 중지된 연결을 다시 켤 수 있습니다. 브라우저가 앱 열기를 요청하면 허용하세요.
FitPoly의 **내 컴퓨터 자동 찾기**를 누르면 폴더·파일 선택 없이 경험 자료를 찾습니다.
브라우저가 로컬 네트워크 연결 권한을 요청하면 허용해주세요.

사용자 폴더·OneDrive와 Windows의 로컬 고정 드라이브를 자동으로 탐색합니다.
시스템·숨김·캐시·프로그램 설치 폴더와 개발 의존성, 자격증명 이름의 파일은 제외합니다.
다른 사용자 폴더, 네트워크 드라이브, 바로가기·심볼릭 링크는 탐색하지 않습니다.

프로그램을 켜는 것만으로 파일을 읽지 않습니다. FitPoly에서 자동 찾기를 눌러야 탐색을 시작합니다.
파일 이름·경로로 관련도를 정렬하고, 영상 대본·외부 조사·예시·템플릿은 후순위로 보냅니다.
브라우저는 직접 한 일이 드러나는 경험을 STAR(상황·과제·행동·결과)로 추출합니다. 역할·성과가 부족한 경험도 보완 후보로 남기며, 없는 내용을 추정하지 않습니다.
자동 찾기와 직접 선택한 파일 모두 제목이 달라도 본문에서 같은 프로젝트·구체적인 작업 내용이 확인되는 자료는 출처와 함께 묶습니다. 기술명·일반 영단어·연락처·폴더만 같거나 서로 다른 프로젝트인 경우는 합치지 않습니다. 중간 자료를 통한 연쇄 병합도 막습니다. 병합 이유를 확인하고 묶음을 다시 나눌 수 있습니다.
같은 프로젝트를 다른 문장으로 설명한 보고서·자소서·포트폴리오도 구체적인 작업 대상과 구현 내용, 원문 수치·성과를 대조해 하나의 경험으로 융합합니다. `3만 건`과 `30,000건` 같은 표기 차이와 원문에 실제 적힌 프로젝트 별칭도 확인합니다. 겹치는 문장만 정리하고 서로 다른 기여·성과와 파일별 원문은 보존합니다. 추가 탐색에서 대표 카드 ID가 달라져도 기존 카드에 반영하며, 편집한 값과 선택은 유지합니다.
‘기간’ 같은 필드명, ‘개발자로 참여하여’ 같은 문장 조각이나 ‘B2B’, ‘HIGHLIGHTS’ 같은 분류·섹션명을 제목으로 사용하지 않고 원문의 프로젝트명·명사형 업무대상을 우선 확인합니다. 코드·연락처·지원 포부는 제목과 STAR 항목에서 제외하고 원문은 출처로 보존합니다. 총 경험 수와 전체 제목 목록을 보여주며, 처음에는 5개를 펼칩니다.
구체적인 직접 기여·판단 과정과 실제 정량·정성 결과가 확인되는 경험을 먼저 정렬하고 ‘추천 경험’과 근거를 표시합니다. 결과 수치가 없어도 실제 완성·활용 결과가 있으면 추천할 수 있습니다. 파일 수·본문 길이·반복 키워드로 순위를 높이지 않습니다. 제목·근거를 보완해야 하는 기록은 아래에 남깁니다.
250,000개 항목·10,000개 지원 문서·하위 40단계 한도에 도달하면 미완료임을 표시합니다.
한 묶음당 최대 30개·150MB를 확인하며, 경험 5개를 찾은 뒤에도 최대 240개까지 계속 읽어 관련 자료와 추가 경험을 찾습니다. 나머지는 **다음 자료에서 경험 더 찾기**로 이어갑니다.

탐색기는 `127.0.0.1:43127`에만 연결되며, FitPoly 허용 출처와 세션 토큰을 확인합니다.
임의 파일 경로를 받지 않고, 해당 세션에서 찾은 문서 ID만 읽습니다. 원본 파일은 수정하지 않습니다.
탐색기는 클라우드나 AI를 호출하지 않습니다. 추출한 텍스트는 웹 화면에서 직군별 분석을 시작할 때만 계정에 저장되고 AI 분석에 사용됩니다.

프로젝트 소스에서 직접 실행하려면 Node.js 22 이상에서 `node local-connector/server.mjs`를 실행할 수 있습니다.
개발 화면(localhost)은 자동 찾기 버튼을 누를 때 개발 서버가 직접 연결하므로 최초 설정도 필요 없습니다.
자동 시작·앱 연결을 해제하려면 설치 폴더의 `remove-connection.ps1`을 실행하세요. 설치 파일과 원문 문서는 삭제하지 않습니다.
자동 시작 없이 일시적으로만 쓰려면 **FitPoly-탐색기-실행.cmd**를 이용하세요.
